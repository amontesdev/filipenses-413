# Code of Conduct

## Our Commitment

This project aims to be a welcoming, respectful, and constructive space for everyone.

Participants are expected to engage in ways that support collaboration, learning, and mutual respect.

## Expected Behavior

- Be respectful and patient.
- Assume good intent, but communicate clearly.
- Offer constructive feedback.
- Be open to different viewpoints and experiences.
- Focus on what is best for the project and community.

## Unacceptable Behavior

- Harassment, discrimination, or abusive language
- Personal attacks or insults
- Trolling or intentionally disruptive behavior
- Sharing private information without permission
- Any conduct that would make others feel unsafe or unwelcome

## Enforcement

Project maintainers may remove, edit, or reject comments, commits, issues, pull requests, or other contributions that violate this Code of Conduct.

## Reporting

To report unacceptable behavior or security-sensitive concerns related to community interactions, please contact the maintainer privately before opening a public discussion.

For security vulnerabilities, see [SECURITY.md](./SECURITY.md).
